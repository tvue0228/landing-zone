# Time Allocator

Splits the time remaining until a target time into equal chunks. Useful for pacing meetings, study sessions, or work blocks.

**Status:** live

## Usage

Open `index.html` in a browser. Enter a target time and number of chunks — the tool shows how much time each chunk gets and auto-refreshes every 10 seconds.

## Extracting this tool

This directory is self-contained. To move it to its own repo, copy the folder contents — there are no dependencies on the parent project.
