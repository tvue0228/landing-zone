# Tools Lab

An R&D repo for micro-tools. Each tool lives in `tools/<name>/` so it can be extracted into its own project whenever it's ready.

**Live:** https://tvue0228.github.io/landing-zone/

## Tools

| Tool | Status | Description |
|------|--------|-------------|
| [Time Allocator](tools/time-allocator/) | live | Splits remaining time until a deadline into equal chunks |

## Adding a tool

1. Create a self-contained directory: `tools/<your-tool-name>/`
2. Add an `index.html` (or whatever the tool needs)
3. Add a card to `index.html` at the repo root
