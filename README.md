# Tools Lab

An R&D repo for micro-tools and games. Each project lives in its own directory and can be extracted into its own repo whenever it's ready.

**Live:** https://tvue0228.github.io/landing-zone/

## Tools

| Tool | Path | Description |
|------|------|-------------|
| [Time Allocator](tools/time-allocator/) | `tools/time-allocator/` | Split remaining time until a deadline into equal chunks |
| [Commander Circuit](tools/commander-tournament/) | `tools/commander-tournament/` | Run a Commander (EDH) tournament with pod pairings, standings, and tiebreakers |
| [Etsy Research Hub](tools/etsy-research/) | `tools/etsy-research/` | Browse curated best-seller ideas and search live Etsy listings |
| [Weight Loss Competition](tools/weight-loss/) | `tools/weight-loss/` | Track competitors, log weigh-ins, rank by percentage lost |
| [PC Parts Builder](tools/pc-parts/) | `tools/pc-parts/` | Build a parts list with instant links to PCPartPicker, Amazon, and Newegg |
| [AI Book Creator](tools/book-creator/) | `tools/book-creator/` | Generate a complete book with chapters and illustrations via Google Gemini |
| [Daily Watchlist](tools/watchlist/) | `tools/watchlist/` | Morning stock & options watchlist generated by a GitHub Actions screener |

## Daily Watchlist

A GitHub Actions workflow runs every weekday at ~8:30 AM ET and commits updated results to `data/daily-watchlist.json`.

- **Screener:** `scripts/daily_watchlist.py` — screens ~60 liquid tickers using yfinance
- **Workflow:** `.github/workflows/daily-watchlist.yml`
- **Data:** `data/daily-watchlist.json`
- **UI:** `tools/watchlist/index.html`

To trigger manually: **Actions → Daily Watchlist → Run workflow**

## Adding a project

- **Tool:** create `tools/<name>/index.html`, add a card to the Live section in `index.html`
- **Game:** create `tools/<name>/index.html` or `games/<name>/index.html`, add a card to the Games section in `index.html`
