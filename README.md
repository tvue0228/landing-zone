## Daily Watchlist

A GitHub Actions workflow runs every weekday at ~8:30 AM ET and commits updated results to `data/daily-watchlist.json`.

- **Screener:** `scripts/daily_watchlist.py` — screens ~60 liquid tickers using yfinance
- **Workflow:** `.github/workflows/daily-watchlist.yml`
- **Data:** `data/daily-watchlist.json`
- **UI:** `tools/watchlist/index.html`

To trigger manually: **Actions → Daily Watchlist → Run workflow**

## Stack & Technology Decisions

All apps are single-file HTML (`index.html`) with no build step — CSS and JS are inlined. Deploy is GitHub Pages.

### Libraries
- **React + Babel (CDN)** — used in Mastermind, Mafia, Imposter. Always pin exact versions: `react@18.3.1`, `react-dom@18.3.1`, `@babel/standalone@7.24.7`. Unversioned CDN URLs can silently break.
- **Google Fonts "Press Start 2P"** — pixel-art font used in Creature Keeper and Pixel Explorer.
- **Canvas 2D** — game rendering in Cookie Lab (particles), Creature Keeper (battle scene), Dino, Pixel Explorer (platformer).
- **localStorage** — all game saves use `localStorage.setItem / getItem` with JSON.

### Layout
- **Mobile-first column layout:** `body { display: flex; flex-direction: column; height: 100%; overflow: hidden }`. Top area = game content (`flex: 1`), bottom = controls panel (`flex-shrink: 0`).
- **Controls panel height:** `height: 46vh` on touch (`@media (pointer: coarse)`), `max-height: 44vh` on pointer devices.
- **Bottom tab bar:** Tab navigation lives at the *bottom* of the controls panel (not the top). Tabs use icon + label stacked vertically, `flex: 1` equal widths.
- **Safe area:** Bottom UI padding uses `max(Npx, env(safe-area-inset-bottom))` for iPhone home indicator.

### Canvas
- **Full-bleed canvas:** Canvas fills its container via `position: absolute; inset: 0; width: 100%; height: 100%`. Do NOT use a fixed `width`/`height` attribute — set those dynamically.
- **resizeCanvas() pattern:**
  ```js
  function resizeCanvas() {
    const area = document.getElementById('canvas-area');
    dpr = Math.min(window.devicePixelRatio || 1, 2);
    W = area.clientWidth; H = area.clientHeight;
    canvas.width = Math.round(W * dpr);
    canvas.height = Math.round(H * dpr);
    ctx.imageSmoothingEnabled = false;
  }
  resizeCanvas();
  window.addEventListener('resize', resizeCanvas);
  ```
- **DPR transform:** At the top of each draw frame: `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` so all drawing coordinates stay in CSS pixels.
- **Scale factor for pixel art:** `const SC = Math.min(W/400, H/220)` — scale decorations/sprites relative to a 400×220 baseline. Positions become `W * fraction`, sizes become `SC * px`.
- **Particle/effects canvas:** A separate `position: absolute; inset: 0; pointer-events: none; z-index: 0` canvas for visual effects layered behind the interactive elements (see Cookie Lab).

### Touch & Mobile
- **Scrollable panels:** Apply `touch-action: pan-y !important` to all children of scrollable containers. This lets the browser handle vertical scroll even when a finger starts on a button. Learned from Creature Keeper roster, applied to Cookie Lab shop.
  ```css
  #shop-content { overflow-y: auto; touch-action: pan-y; }
  #shop-content * { touch-action: pan-y !important; }
  ```
- **Buttons in scrollable areas:** Use `click` listeners only — no `touchstart` + `e.preventDefault()`, which would cancel the scroll gesture. `user-scalable=no` in the viewport meta eliminates the 300ms tap delay so `click` fires instantly.
- **Primary tap targets (outside scrollable areas):** Use `touchstart` + `mousedown` for maximum iOS responsiveness where scroll doesn't apply (e.g., the cookie button inside `overflow: hidden`).
- **iOS text input zoom:** Font size on `<input>` and `<textarea>` must be **≥ 16px** to prevent iOS Safari from auto-zooming the viewport.

### React / Babel Apps
- **Loading state:** Include a `<div id="root">Loading…</div>` placeholder. Add an 8-second guard that shows a Retry button if the app hasn't mounted (catches CDN timeout).
- **CSS in JS:** Store CSS as a template literal and inject via `<style>{CSS}</style>` so the JSX stays self-contained.

### Saving & Data
- **Save key:** Each game uses a unique localStorage key (e.g., `cookie_lab`, `creature_keeper`).
- **Offline earnings:** Cap at 8 hours (`Math.min(elapsed, 8 * 3600)`) to prevent extreme accumulation. Show a toast on return.
- **Gear/multiplier architecture:** Apply multipliers as separate functions (`gearClickMult()`, `gearCpsMult()`) computed at use-time on top of base values. Never mutate the base values — keeps upgrade systems independent.
